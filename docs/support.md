# Support / 技术支持

Chessmirror (棋镜)

## English

- **A bug, a question, an idea:** open an issue at
  https://github.com/sunfmin/chessmirror/issues. Say which build you are on — 关于 (About) in
  the app shows it.
- **Where are my games?** In the Files app, under iCloud Drive → 棋镜. Each game is a PGN file
  you can copy, share or open in any other chess program.
- **A board was read wrongly.** The confirm screen lets you fix any square, the side to move and
  castling rights before the game opens. Photographs taken from above, with the whole board in
  frame, read best.
- **Source code:** https://github.com/sunfmin/chessmirror (GPLv3).

## 中文

- **有 bug、有疑问、有想法：** 到 https://github.com/sunfmin/chessmirror/issues 提一个 issue，
  写上你用的是哪个构建——App 里「关于」看得到。
- **我的对局在哪？** 「文件」App 里，iCloud Drive → 棋镜。每盘棋是一个 PGN 文件，可以拷贝、分享，
  或在任何别的国际象棋软件里打开。
- **棋盘识别错了。** 确认局面那一屏可以改任何一格、轮到谁走和易位权，改好再开局。从正上方拍、
  整个棋盘都在画面里，识别得最好。
- **源代码：** https://github.com/sunfmin/chessmirror （GPLv3）。
